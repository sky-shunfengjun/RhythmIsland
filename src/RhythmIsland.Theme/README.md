# 律动岛背景主题

这是“律动岛 · RhythmIsland”插件的独立配套背景主题，用于在 ClassIsland 的主要行背景中显示实时频谱。

> 当前版本：`1.0.0.0 公开测试版`

## 使用前提

本主题必须依赖律动岛插件：

- 主题包不包含 `RhythmIsland.dll`。
- 必须先安装并启用律动岛插件。
- 插件未加载时，主题会提示未检测到律动岛插件，并保留 ClassIsland 原背景。

## 安装和加载顺序

1. 安装并启用律动岛插件。
2. 从 [GitHub Releases](https://github.com/sky-shunfengjun/RhythmIsland/releases) 下载 `RhythmIsland.Theme.zip` 并安装。
3. 在 ClassIsland 的主题加载顺序中，将本主题放在 Fluent 或 Classic 之后。
4. 在律动岛插件设置页打开“背景频谱”。

主题不会自动打开声音捕获。需要先在插件设置页打开声音捕获总开关，背景频谱才会随声音更新。

## 背景频谱设置

背景频谱的设置位于律动岛插件设置页：

- 默认使用 `240px` 固定长度并居中显示。
- 主界面宽度小于设定长度时，只裁剪超出部分，不压缩频谱。
- 背景频谱默认不透明度为 `0.80`。
- 背景频谱的不透明度独立于 ClassIsland 原背景不透明度；即使原背景完全透明，频谱仍可单独显示。
- “背景频谱”开关只关闭背景层，不会关闭普通“律动岛频谱”组件。

主题复用插件中的样式、颜色、渐变、发光、中心镜像和频率补偿能力。背景没有普通组件的长度和无声自动收起设置。

## 兼容和降级

- Fluent 和 Classic 是首要兼容目标。
- 插件被禁用时，原背景会保留，背景频谱会被清理。
- 第三方主题如果没有兼容的主要行背景结构，律动岛会安全跳过挂载，不覆盖其模板内容。
- 主题与插件通过稳定的 `RhythmIsland.BackgroundBridge/v2` 桥接协议协作。

如果主题状态显示结构不兼容或版本不匹配，请确认主题位于 Fluent 或 Classic 之后，并同时更新插件和主题包。

## 隐私说明

主题本身不读取或保存音频，频谱数据由律动岛插件在内存中实时处理。

## 第三方说明

主题包只包含主题清单、XAML、说明、许可证和展示图，不包含 `RhythmIsland.dll`。

仓库首页展示图中，歌曲信息和封面由 MediaIsland 显示，歌词由 ExtraIsland 显示；这只是截图展示环境，不是主题的必要安装项。

本项目在主题设计和文档编写过程中使用了 AI 工具辅助，最终内容由项目作者审阅、修改和验证。
