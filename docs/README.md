# 律动岛开发文档

律动岛（RhythmIsland）是面向 ClassIsland 2.x 的实时音乐频谱插件。它读取 Windows 当前默认扬声器正在播放的声音，在内存中计算频谱，并通过可添加、可调整宽度的 ClassIsland 主界面组件显示柱状动画。

项目作者为 `sky-shunfengjun`，采用 `GPL-3.0-or-later` 许可证。当前仓库已实现设置存储、默认扬声器捕获、频谱分析、自动重连、诊断设置页和“律动岛频谱”组件。插件和未来的背景主题已经拆分，当前插件不会安装、注册或启用主题。

## v0.1 目标

v0.1 是可实际安装体验的 Windows 原型，优先验证实时音频、频谱分析、主界面组件和长期运行性能。

用户需要先在插件设置页主动打开主开关，再在 ClassIsland 编辑模式中添加“律动岛频谱”组件。每个组件都能在自己的设置页中分别调整长度、柱数、幅度、透明度、方向和颜色。

包含：

- Windows 10/11 x64 与 ClassIsland 2.1.0.1。
- 自动捕获当前默认扬声器的系统混音。
- 每个组件独立选择“底部向上”或“上下镜像”。
- 默认跟随组件前景色，也可为单个组件选择固定颜色。
- 每个组件独立设置 60–1200px 长度、24–96 柱、0.25×–3.00× 幅度和 0.10–1.00 透明度；长度、幅度和透明度使用滑块，柱数使用选择框，自动收起等待时间使用数字输入框。
- 每个组件可以在无声 1–120 秒后自动收起，恢复声音时自动显示，编辑模式下不会自动隐藏。
- 基于 ClassIsland 原生控件的折叠设置页。
- 独立主题源码骨架；当前不随插件发布。
- 默认设备变化后的自动重连和可读的运行状态。

暂不包含：

- 录音、音频文件保存、音频上传或联网分析。
- 麦克风输入、指定单个软件的声音捕获或手动选择声音设备。
- 波形、渐变、彩虹、粒子等其他视觉模式。
- Linux、macOS、Windows x86 或 Windows ARM64 支持。
- 对所有第三方 ClassIsland 主题的兼容承诺。

## 核心原则

1. **隐私优先**：音频只在内存中实时计算，不形成可回放数据。
2. **宿主稳定优先**：插件失败时停用自身，不得拖垮 ClassIsland。
3. **兼容优先**：配套主题不复制或接管 ClassIsland 的完整模板。
4. **省资源优先**：默认使用 30 FPS、48 柱，60 FPS 作为高级选项。
5. **用户主动控制**：首次安装不自动启用，也不擅自改变主题组合。

## 成功标准

当当前组件版本完成验收时，用户应能安装一个 `.cipx` 包，在设置页主动启用捕获，并添加一个或多个可调长度的实时频谱组件。关闭音乐时频谱应平滑归零并按组件设置自动收起；禁用插件后应停止捕获并清空组件画面。

构建成功只能证明代码可以编译，不能证明上述交互、声音设备切换和长期运行已经通过真实环境验证。
