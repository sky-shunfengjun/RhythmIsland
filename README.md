# 律动岛 · RhythmIsland

本仓库同时维护 ClassIsland 插件与未来的独立背景主题。

- `src/RhythmIsland.Plugin`：当前开发和发布的插件，包含声音捕获、频谱分析、内置 Windows 媒体封面取色与鲜艳/柔和/偏色模式，以及支持动态渐变和激光发光的柱状/曲线主界面频谱组件。
- `src/RhythmIsland.Theme`：独立主题源码，目前仅保留不改变外观的开发骨架。
- `tests/RhythmIsland.Tests`：插件自动化测试。
- `docs`：架构、开发指南与路线图。

当前只发布 `cipx/RhythmIsland.cipx`，不会随插件安装或启用主题。
