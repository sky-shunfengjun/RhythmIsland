# 律动岛 · RhythmIsland

律动岛是面向 ClassIsland 的实时音频频谱背景插件。

当前 `0.1.0.0` 版本包含设置保存、默认扬声器回环捕获、频谱分析、诊断页面和“律动岛频谱”主界面组件。插件不会安装、注册或改变 ClassIsland 主题。

## 使用方式

1. 在 ClassIsland 的插件市场页面安装 `RhythmIsland.cipx`。
2. 重启 ClassIsland。
3. 打开“设置 → 插件 → 律动岛”，主动开启声音捕获。
4. 在 ClassIsland 编辑模式中添加“律动岛频谱”组件。
5. 播放声音后，检查组件、设备名称、频谱帧时间和峰值是否持续变化。

每个频谱组件都有独立设置：可以选择柱状频谱、平滑线条或曲线填充，并分别设置方向、长度、细节数量、幅度、透明度、帧率、主题色/音乐封面（SMTC）/自选颜色、封面的鲜艳/柔和/偏色模式、静态或动态渐变、发光和无声自动收起。新组件透明度默认 1.00；固定帧率档位会按当前显示器能力过滤，“更高（不推荐）”跟随当前显示器；调整一个组件不会改变其他频谱组件。

“平滑线条”和“曲线填充”使用现有频率数据绘制，不保存真实音频波形。颜色默认跟随 ClassIsland 主题强调色；选择音乐封面（SMTC）时，插件自行读取 Windows 系统当前媒体封面并在内存中取色，不需要 MediaIsland。封面颜色默认使用鲜艳模式保证可见度，也可改为适度柔和或按主色生成同色系偏色；无封面或系统接口不可用时自动回退主题色。渐变和激光发光默认关闭；动态渐变提供 10 秒、6 秒和 3 秒三档。旧组件升级后保留原有透明度和外观设置。

插件默认关闭。关闭开关后会停止捕获。

## 隐私

音频只在内存中实时计算；插件不写入音频文件、不联网、不上传音频，也不保存能够还原原始音频的历史数据。媒体封面同样只在内存中用于取色，不保存封面、歌曲标题或播放历史。

## 兼容范围

- Windows 10/11 x64
- ClassIsland 2.1.0.1
- .NET 8
