# 架构设计

## 1. 目标与边界

律动岛 v0.1 是运行在 ClassIsland 进程内的 Windows 插件。它通过 WASAPI 回环捕获默认输出设备的系统混音，生成频谱数据，再使用 ClassIsland 主界面组件中的 Avalonia 自绘控件显示频谱。

插件不得录制、保存、上传或联网发送音频，也不得按控件名称查找或修改 ClassIsland 内部视觉树。

## 2. 总体数据流

```text
Windows 默认扬声器
        ↓ WASAPI 回环捕获
交错声道 PCM / IEEE Float 数据
        ↓ 转为 [-1, 1] 单声道浮点样本
2048 点滑动窗口（50% 重叠 + Hann 窗）
        ↓ FFT
50 Hz–16 kHz 对数分布频段
        ↓ 幅度归一化、灵敏度与平滑
最新 SpectrumFrame
        ↓ 每秒 30 次读取
共享的 30 FPS SpectrumRenderClock
        ↓
一个或多个 ClassIsland“律动岛频谱”组件
```

音频回调和分析过程不得操作 Avalonia 控件。界面线程只复制最新一帧的频段值并请求重绘，避免声音处理阻塞课程表界面。

## 3. 模块边界

以下名称是项目内部边界，不是给其他插件使用的公共 SDK。

### `IAudioCaptureService`

职责：

- 打开 Windows 当前默认渲染设备的 WASAPI 回环捕获。
- 将常见 IEEE Float 32 位及 PCM 16/24/32 位数据转换为单声道浮点样本。
- 报告 `Stopped`、`Starting`、`Running`、`DeviceUnavailable`、`Faulted` 状态和最近一次错误。
- 监听默认输出设备变化，并串行停止旧捕获、启动新捕获。
- 捕获异常后在插件仍启用的前提下延迟重试；停止期间不得再安排重试。

服务只产生短生命周期样本，不暴露录音文件或无限增长的缓存。

### `ISpectrumAnalyzer`

职责：

- 使用 2048 点 FFT、1024 样本步长和 Hann 窗。
- 在 50 Hz 到 `min(16000 Hz, Nyquist)` 之间建立对数频段。
- 固定输出 96 个分析频段，再由各组件按自身柱数设置重采样为 24、32、48、64 或 96 柱。
- 将频段幅度限制在有限范围内，过滤 `NaN` 和无穷值。
- 先快速响应上升，再较慢回落；没有新音频包时持续向零衰减。
- 低于 `0.005` 的幅度统一归零；静音帧不绘制退化矩形，避免主界面底部残留横线。

声音设备采样率变化时重建频段映射，不重启 ClassIsland。组件柱数变化只影响该实例的绘制，不会重启或重配共享分析器。

### `ISpectrumFrameProvider`

职责：

- 在线程之间发布和读取最新一帧归一化频段值。
- 只保留最新状态，不排队积压旧帧。
- 不把分析线程持有的可变数组直接交给 UI。
- 停止捕获时通过 `Clear()` 清除旧帧，避免组件保留停止前画面。

`SpectrumFrame` 至少包含频段值、生成时间和是否处于静音状态。运行状态与错误信息由独立状态模型提供，不写入频谱数组。

### `ISpectrumRenderClock`

职责：在 Avalonia UI 线程提供共享刷新节拍。首个频谱组件订阅时启动，最后一个组件解绑时停止；每个组件只请求重绘并读取最新帧，不启动独立后台任务。

### `SpectrumComponent` 与 `SpectrumBarsControl`

组件通过 ClassIsland `AddComponent` 正常注册，不直接挂载主窗口视觉树。`SpectrumBarsControl` 单次自绘全部柱体；每个组件实例独立保存长度、柱数、幅度、透明度、方向、颜色和无声自动收起设置。组件默认宽度为 240px，避免在没有频谱帧时被宿主测量为零宽度。

### `RhythmIslandSettingsStore`

职责：

- 从 `PluginConfigFolder/settings.json` 加载设置。
- 对枚举、数值范围和颜色文本进行校验；无效字段回退到默认值。
- 设置改变后先写入同目录临时文件，再原子替换正式文件。
- 读取或保存失败时记录警告，继续使用内存中的安全默认值。

主题不属于插件设置；插件不读取或修改 ClassIsland 的主题列表。

## 4. 生命周期与线程

1. `Plugin.Initialize` 只注册服务、设置页和频谱组件，不注册主题、不访问主窗口。
2. 后台运行服务订阅 `AppStarted` 和 `AppStopping`。
3. 用户主开关启用后启动声音捕获和分析；添加组件本身不会自动读取声音。
4. 频谱组件进入视觉树时订阅共享刷新时钟，离开时立即解绑。
5. `AppStopping` 中先阻止重连，再停止捕获、分析任务并清除最新帧。

设备切换、捕获停止和设置变化可能同时发生，所有启动/停止操作必须经过同一个串行化入口，保证同一时间最多存在一个捕获实例。

## 5. 频谱绘制

`SpectrumBarsControl` 直接重写 Avalonia 绘制方法，不为每根柱创建独立控件。

- **底部向上**：柱体从控件底边向上生长，最大高度不超过可用高度。
- **上下镜像**：以垂直中心为轴，同一频段向上下两侧对称生长。
- 柱宽根据控件实时宽度和柱数计算；间隔使用柱槽宽度的固定比例，窄窗口下不得产生负宽度。
- 默认跟随组件前景色；每个组件可选择自定义颜色。
- 频谱整体透明度由控件处理，每个组件默认 0.65。
- 绘制控件启用边界裁剪，所有柱体坐标先夹到控件范围内。“底部向上”模式预留上 1px、下 3px、左右各 1px 的安全区域，避免柱体越过宿主底部圆角；“上下镜像”保持原有完整绘制区域和边距。静音帧直接跳过绘制。
- 所有输入值在绘制前限制到 `[0, 1]`，零尺寸控件直接跳过绘制。

绘制刷新默认为 30 FPS，可在高级设置切换到 60 FPS。FFT 产生数据的频率和 UI 重绘频率相互独立。

## 6. 设置与默认值

| 设置 | 默认值 | 允许范围或选项 |
|---|---:|---|
| 是否启用 | 否 | 是 / 否 |
| 组件显示模式 | 底部向上 | 每个组件独立：底部向上 / 上下镜像 |
| 组件颜色 | 跟随组件前景色 | 每个组件独立：跟随 / 自选色 |
| 组件长度 | `240px` | 每个组件独立：`60–1200px` |
| 组件幅度 | `1.00×` | 每个组件独立：`0.25×–3.00×` |
| 频谱透明度 | `0.65` | 每个组件独立：`0.10–1.00` |
| 灵敏度 | `1.00` | `0.50–3.00` |
| 平滑程度 | `0.65` | `0.00–1.00` |
| 柱数 | `48` | 每个组件独立：`24 / 32 / 48 / 64 / 96` |
| 绘制帧率 | `30` | `30 / 60` |
| 无声自动收起 | 开启 | 每个组件独立：关闭，或无声 `1–120` 秒 |

设置页采用 ClassIsland 自带的 `SettingsPageBase`、Fluent Avalonia `SettingsExpander`、`SettingsCard`、`Separator` 和 Fluent 图标，不引入另一套 UI 框架。页面按以下顺序分组：

1. **运行状态**：主开关和隐私说明。
2. **捕获诊断**：状态、默认设备、最近帧、峰值和错误。

长度、柱数、幅度、透明度、方向、颜色与无声自动收起不放在插件设置页，而是保存在 ClassIsland 的每个组件实例设置中。长度、幅度和透明度使用滑块，柱数使用固定选项选择框，自动收起等待时间使用数字输入框；幅度和透明度以 `0.05` 为步进，提示显示两位小数。编辑模式下自动收起暂时失效，便于选择和修改组件。

## 7. 独立主题边界

主题 ID `rhythmisland.spectrum-background` 只保留在 `src/RhythmIsland.Theme`。主题使用独立 `manifest.yml` 和根对象为 `<Styles>` 的 `Styles.axaml`，不编入插件、不由插件注册，也不参与当前发布。未来主题必须单独打包、安装、启用和验收。

## 8. 隐私与故障降级

- 音频样本、FFT 缓冲和频谱帧只存在于内存，使用后立即覆盖或释放。
- 不提供录音 API，不写音频文件，不发送网络请求，不记录原始样本到日志。
- 日志只包含设备显示名、状态、时间和异常信息，不包含音频内容。
- 没有输出设备、格式不支持或设备被占用时，设置页显示状态，组件保持空白。
- 捕获或分析异常不得传播到 UI 线程顶层；应记录并停止当前捕获，再按策略重试。
- 插件不尝试修改 ClassIsland 仓库或使用运行时补丁绕过宿主行为。
